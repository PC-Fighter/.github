## 🥊 Quiénes somos

PC Fighter nace de un técnico que también es boxeador. Enfrentamos cada desafío técnico
con la misma determinación que una pelea: estudiando al rival, sin atajos y sin tirar
la toalla.

## 💻 Qué hacemos

| | |
|---|---|
| **Desarrollo a medida** | Sistemas internos, integraciones entre herramientas y automatización de procesos |
| **Servidores** | Windows Server y Linux, virtualización, Docker, migraciones |
| **Redes** | Cableado estructurado, VLANs, VPN, firewall |
| **Soporte con abono** | Mantenimiento preventivo, remoto y en sitio, con tiempos de respuesta por escrito |

## 🏆 Trabajos

- **[Palillo Fight Club](https://github.com/PC-Fighter/fichaje_pfc)** — asistencia, cuotas y

  técnicos, con seguimiento por número de ticket.
